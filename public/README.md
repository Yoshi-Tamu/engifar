# EngiFar

Webの基礎クイズでロケットの推進力をため、クルーと宇宙を目指すブラウザゲームです。HTML・CSS・JavaScriptだけで動作します。

## 画面構成

1. `index.html` — プレイヤー名と自由なクルーカラーを設定し、ルームを作成・参加
2. `room.html` — 招待コードと出発クルーを表示するロビー
3. `quiz.html` — 24問のWeb基礎クイズ（10秒回答・5秒答え合わせ）
4. `rocket.html` — クルー搭乗、カウントダウン、段階的なロケット飛行、到達ランク演出
5. `result.html` — 到達ランク、出力強度、安全性、到達高度、6分野レーダーチャートを表示
6. `card.html` — ランクと6角形レーダーチャート入り自己紹介カードをPNG保存

## スコア

- 出力強度：難易度の重みを含む正答率
- 安全性：6分野の得点率を平均したバランス値
- 軌道到達ライン：出力強度60%以上、かつ安全性75%以上
- 到達ランク：高度に応じて「不時着級」から「未知の惑星到達級」までの8段階

ルーム情報はプレイヤーやクイズ記録と分けて保持しているため、今後の通信処理や複数メンバー同期へ接続しやすい構成です。

`index.html` をブラウザで開くとスタートできます。各画面はデスクトップ・スマートフォン・横向き表示に対応しています。

ホームでは最初のアクセス時に画像付きの遊び方ガイドを表示します。ホームとルームの「遊び方」ボタンからいつでも再表示できます。
